情況：對方只有 Windows 電腦。

**好的回法：**
對方：Windows 可以用嗎
我們：可以喔，Windows 也能用 🙌 這是購買教學［按鈕］

**不要這樣：**
我們：目前只支援 Mac，Windows 還不能用

為什麼：Mac 和 Windows 都能用，絕對不能說 Windows 不能用。
